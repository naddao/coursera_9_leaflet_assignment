# coursera_9_leaflet_assignment
In this report, we practice to view information in leaflet maps visualization. Leaflet is a library which can be integrated with R and be helpful to visualize data together with maps.
This report aim to use library leaflet with choropleth map to visualize population data in 77 provinces of Thailand(data in year 2024).

Repositories contain files as follows:-

- leaflet_assignment.Rmd: Report in .Rmd format 
- leaflet_assignment.html: Generated report in .html format
- simplified_provinces_geojson.geojson: map data in GeoJSON format describe boundary of 77 provinces in Thailand.
- stat_c67.txt: Thailand population data by each province in year 2024.
